# 모델 카드

## 모델 개요

| 항목 | 내용 |
|---|---|
| 모델명 | 수상한 시그널 |
| 과제 | 하수 감시 기반 감염병 유행 조기예측 |
| 예측 단위 | 대한민국 17개 시·도, 주간 |
| 예측 시점 | 원점으로부터 2주 뒤 |
| 출력 | 농도 예측값과 급증 경보 0/1 |
| 핵심 알고리즘 | HistGradientBoostingRegressor 2개와 규칙 기반 경보 |

## 의도한 사용

지역별 하수 바이러스 농도의 변화를 미리 파악해 감염병 감시와 대응 준비를 보조하는 연구·분석용
모델이다. 지역 간 위험을 단정하거나 의료적 판단을 자동화하는 용도로 설계하지 않았다.

## 입력

- 지역별 주간 하수 바이러스 농도와 기준 농도
- 측정 지점 수와 표본 인구
- 전국 하수 농도와 임상 신고 수
- ASOS 일별 강수량·평균기온과 품질 플래그
- 예측 원점까지의 지역별 과거 이력

대회 원본 데이터는 저장소에 포함하지 않는다.

## 출력

공식 평가 키 `(region, date_week)`마다 다음 값을 반환한다.

| 열 | 형식 | 설명 |
|---|---|---|
| `pred_conc` | 유한한 0 이상 실수 | 2주 뒤 하수 바이러스 농도 |
| `pred_alert` | 정수 0 또는 1 | 기준 농도 대비 급증 경보 |

## 평가 방식

공식 평가기의 10개 롤링 창을 사용한다. 평가 창마다 모델을 새로 학습하므로 미래 창의 학습 상태를
재사용하지 않는다.

```text
창 점수 = 0.6 × (1 - 모델 sMAPE / 공식 기준선 sMAPE)
        + 0.4 × Macro-F1

최종 정량점수 = 10개 창 점수의 평균
```

## 성능

| 모델 | 최종 정량점수 |
|---|---:|
| 공식 나이브 기준 모델 | 0.2212 |
| 최종 모델 | **0.2870000543** |

- 기준 모델 대비 절대 `+0.0658`, 상대 약 29.7% 개선
- 최저 평가 창 점수 `0.2015621`
- 평가 키 2,159개와 정확히 일치
- 누락·중복·추가 키, NaN·Inf·음수 농도, 잘못된 경보값 0건

이 점수는 대회 배포 데이터의 로컬 공식 평가 결과이며 대회 순위나 미래 성능을 보장하지 않는다.

## 주요 설계 결정

### 로그 변환

농도 분포의 범위가 매우 넓어 원 스케일의 큰 관측이 손실을 지배하지 않도록 농도와 주요 양수형
변수에 `log1p`를 적용했다.

### 두 개의 회귀기

수준 모델은 절대 농도에 강하고 변화량 모델은 상승·하락 배율에 집중한다. 변화량 모델을 단독으로
사용하지 않고 10%만 결합해 급변 구간을 보완했다.

### 회귀 연계 경보

직접 분류기는 작은 표본과 시점별 양성 비율 변화에 취약했다. 최종 농도 예측을 기준 농도와 직접
비교하는 방식으로 회귀와 분류가 같은 미래 신호를 공유하게 했다.

## 한계

- 하수 농도는 강수, 채취 일정, 처리장 구성과 측정 품질의 영향을 받는다.
- 일부 평가 창에서는 공식 회귀 기준선보다 낮아 시점 변화에 완전히 강건하지 않다.
- 공개된 과거 평가 창에서 선택한 혼합비와 임계값이 미래 기간에도 최적이라는 보장은 없다.
- 임상 신고와 하수 신호 사이의 관계가 변하면 재학습과 재검증이 필요하다.
- 예측은 역학·임상 전문가의 판단을 대체하지 않는다.
