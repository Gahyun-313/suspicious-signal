# 수상한 시그널 - 문제해결 방법 설명서

## 1. 프로젝트 개요

- 대회: 2026 KISTI DATA·AI 분석 경진대회
- 과제: 하수 감시 데이터 기반 감염병 유행 조기예측 AI 모델 개발
- 팀명: 수상한 알파카
- 프로젝트명: 수상한 시그널
- 목표: 원점 시점까지 공개된 하수 감시·전국·기상 자료만 이용해 지역별 2주 뒤
  바이러스 농도와 급증 경보를 예측한다.

## 2. 활용 데이터

공식 배포 데이터 v2.5를 사용했다. 핵심 입력은 지역별 주간 하수 바이러스 농도,
기준 농도, 측정 지점 수, 표본 인구, 전국 농도·임상 신고 자료와 ASOS 일별
강수·기온 자료다. 외부에서 임의로 수집한 데이터는 사용하지 않았다.

평가 시점 이후의 행과 라벨은 사용하지 않는다. ASOS 자료 역시 공식 평가기가
각 예측 원점까지 잘라 전달한 `aux`만 지역·주차 단위로 집계한다.

## 3. 데이터 전처리와 특성 생성

농도와 인구처럼 오른쪽 꼬리가 긴 양수형 값에는 `log1p` 변환을 적용했다.
빈 문자열 결측은 NaN으로 보존한 뒤 학습 창의 중앙값으로 대체하고, 결측 여부를
별도 특성으로 추가했다.

주요 특성은 다음과 같다.

- 지역·연도와 주차의 사인·코사인 계절성
- 현재부터 8주 전까지의 지역 농도 지연값
- 최근 3·4·6·8·12주의 농도 수준, 변동성, 관측률
- 최근 유효 관측 사이의 로그 변화량
- 전국 농도와 임상 신고 수의 최근 5주 지연값
- 원점과 최근 4주의 지역별 ASOS 강수·기온 집계

배포 `conc_3wk_avg`에는 미래값 혼입 가능성이 알려진 행이 있어 출력 보정에 직접
사용하지 않았다. 대신 원점 이하 `conc_mean`의 최근 3개 유효 관측으로 안전한
후행 평균을 다시 계산했다.

## 4. 모델 개발 방법

표본 규모와 재현성을 고려해 두 개의 규제된 HistGradientBoostingRegressor를
사용했다.

1. 수준 모델은 2주 뒤 농도의 `log1p` 값을 예측한다.
2. 변화량 모델은 현재부터 2주 뒤까지의 로그 농도 변화량을 예측한다.
3. 수준 모델은 현재 농도와 안전한 최근 3주 평균을 함께 사용해 급격한 분포
   변화에 대한 예측을 안정화한다.
4. 최종 농도는 수준 모델 90%와 변화량 모델 10%를 로그 공간에서 결합한다.
5. 급증 경보는 최종 예측 농도 80%와 현재 농도 20%의 기준선 대비 로그 비율이
   `log(1.09)` 이상인지로 판단한다.

모든 혼합비와 경보 임계값은 특정 지역이나 특정 평가 창에 별도 상수를 두지 않고
10개 공식 롤링 평가 창 전체에 동일하게 적용했다.

## 5. 실험 및 평가

공식 `evaluation.py`의 10개 롤링 평가 창을 사용했다. 각 창마다 모델을 새로
학습하고 예측 원점 이후의 패널·전국·ASOS 자료와 미공개 라벨을 차단했다.

| 모델 | 최종 정량점수 |
|---|---:|
| 공식 나이브 기준 모델 | 0.2212 |
| 최종 제출 모델 | **0.2870** |

최종 정확한 재현 점수는 `0.2870000543`이다. 공식 기준 모델 대비 약 29.7% 높은
점수이며, 최저 평가 창 점수는 `0.2015621`이다. 이 결과는 배포 데이터의 로컬
롤링 평가 결과이며, 이후 기간의 성능이나 최종 순위를 보장하지 않는다.

LightGBM, CatBoost, 직접 경보 분류, 지역 원-핫, 최근성 가중, 전국 농도 앵커와
계절별 앙상블도 같은 검증 조건에서 비교했으나 최종 모델보다 낮아 제외했다.

## 6. 재현성과 실행 방법

Python 3.9.13, NumPy 1.26.1, pandas 2.1.2, scikit-learn 1.3.2를 기준 환경으로
고정했다. 모델자료 ZIP의 `RUN_MANUAL.md`에 설치와 공식 평가 명령을 제공한다.
난수 시드는 2026으로 고정했으며 원본 데이터는 제출물에 포함하지 않는다.

## 7. 기대효과와 한계

지역별 하수 농도의 2주 선행 신호를 이용하면 임상 신고 증가 이전에 유행 가능성을
확인하고 검사·의료 대응 자원의 사전 배치 판단을 보조할 수 있다. 모델은 결측과
지역별 측정 규모 차이를 고려하며, 농도 예측과 경보를 함께 제공한다.

다만 하수 농도는 강수, 표본 채취, 처리장 구성과 측정 품질의 영향을 받는다.
따라서 예측은 단독 의사결정 수단이 아니라 역학·임상 정보와 함께 검토해야 하며,
새로운 기간의 자료가 쌓이면 롤링 검증과 재학습이 필요하다.
